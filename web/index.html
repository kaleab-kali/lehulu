Sign-up that works
for everyone

Lehulu is the sign-up, profile and job-application part of a learning platform. Learners join by typing or by voice, in Amharic or English, with no ID document. It never asks about disability; it asks how the learner uses their phone, and every screen follows that answer.

How it works

  1. Say how you use your phoneSix ways, any mix. Nothing about diagnosis.
  2. Answer one question at a timeType, speak, or tap a picture. Each question can be played aloud.
  3. No ID? A partner confirmsAAAPD confirms who you are, and learning starts the same day.
  4. Apply for jobsJobs with your support come first. You decide what the employer sees.
  5. Change, download or deleteSign in on any phone with a code sent by SMS.

Add it to your platform

1. Load the script once, and place the sign-up where it should appear.

<script type="module" src="https://lehulu.com/lehulu.js"></script>
<lehulu-signup lang="am" jobs-url="/jobs" profile-url="/profile"></lehulu-signup>

2. Listen for what the learner did. Your platform decides what happens next.

document.addEventListener('lehulu:signup-complete', (e) => {
  // e.detail: { learnerId, idStatus, linkToken }
});
document.addEventListener('lehulu:preferences', (e) => {
  // Only if the learner agreed: { language, accessPreferences }
});
  • Level 1

    Web components: <lehulu-signup>, <lehulu-jobs>, <lehulu-profile>, <lehulu-partner>, <lehulu-employer>. An iframe for sites that block scripts.

  • Level 2

    A REST API with OpenAPI documentation, a signed webhook, and account linking for the host.

  • Level 3

    schema.org JobPosting for every job. One Docker command, SQLite, no cloud services. The plain page example shows the sign-up with no styles around it.
